Blinkit Sales Analysis Dashboard | Power BI

Project Overview

This project focuses on analyzing Blinkit's sales performance and business metrics using Microsoft Power BI. An interactive dashboard was developed to transform raw sales data into meaningful business insights.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning

Dashboard Features

- Total Sales Analysis
- Average Sales
- Number of Items
- Outlet-wise Sales Performance
- Item Type Analysis
- Outlet Size and Location Analysis
- Interactive Filters and Slicers
